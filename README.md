#  Shopora - E-Commerce Platform

Shopora is a full-stack e-commerce web application built using Python. It allows users to browse products, add items to cart, and place orders with a smooth and user-friendly experience.

---

##  Features

-  User registration and login system  
-  Product listing and category management  
-  Add to cart / remove from cart  
-  Order placement system  
-  Product search functionality
-  Order tracking system  
-  Admin panel for managing products and orders  

---

##  Tech Stack

- Python  
- Django / Flask (backend)  
- SQLite / MySQL (database)  
- HTML / CSS / Bootstrap (frontend)  
- JavaScript (basic interactivity)

##  How It Works

1. User registers and logs in  
2. Browses available products  
3. Adds products to cart  
4. Reviews cart and places order  
5. Admin manages products and orders  

---

##  Installation

```bash
git clone https://github.com/yourusername/shopora.git
cd shopora
pip install -r requirements.txt
```

---

##  Run Project

```bash
python manage.py migrate
python manage.py runserver
```
